# eztvXrss

RSS feeds for TV show releases from the EZTV API, filtered by IMDb ID, resolution and codec. Modular PHP
(PSR-4, standard library only), live at https://code-alongsi.de/eztvxrss/. Example:
`feed.php?imdb=12327578&resolution=1080p&codec=x265`.
